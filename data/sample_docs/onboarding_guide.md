# Welcome to Meridian Labs
Welcome to Meridian Labs! This onboarding document outlines your first week agenda, required developer tooling, and essential contacts.

# First Week Schedule
- Day 1: IT hardware provisioning and credentials setup with Elena Vance.
- Day 2: System architecture overview and security compliance walkthrough with Marcus Thorne.
- Day 3: Team welcome lunch followed by codebase architecture walkthrough and first pull request submission.
- Day 4: Deep dive into Lumen Gateway deployment pipelines with the platform engineering squad.
- Day 5: First-week retrospective with your engineering buddy and manager.

# Standard Engineering Tooling
All engineers are provisioned access to the following core software stack:
- Communication: Slack (workspace meridianlabs.slack.com)
- Project Tracking: Jira Software
- Version Control: GitHub Enterprise
- Network Access: Tailscale VPN with zero-trust mesh routing
