# Password Rotation & Credentials
All employee domain and single sign-on (SSO) passwords must undergo mandatory password rotation every 90 days. Passwords must be a minimum of 16 characters in length and include uppercase letters, numbers, and symbols. Re-use of previous 10 passwords is prohibited. Multi-factor authentication (MFA) via hardware security key or authenticator app is enforced on all access points.

# Incident Reporting SLA
Any suspected security breach, compromised credential, or lost hardware must be reported immediately. The incident reporting SLA requires submission of an incident ticket to security@meridianlabs.internal within 1 hour of discovery. The Security Operations Center (SOC) operates 24/7/365.

# Corporate Device Policy
All company laptops and workstations must run approved endpoint protection software: BitLocker full-disk encryption and CrowdStrike Falcon agent are mandatory. Personal USB storage devices are blocked by default. Operating system updates must be applied within 72 hours of release.
